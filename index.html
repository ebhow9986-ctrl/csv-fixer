よくある質問：Excel で CSV が文字化けするとき

なぜ Excel で CSV が文字化けするのですか？

CSV には「どの文字コードで書かれたか」という情報がありません。Windows 版の Excel は、BOM（ファイル先頭の目印）のない CSV をパソコンの既定の文字コード（日本語環境では多くの場合 Shift_JIS）として読むことがあるため、BOM なしの UTF-8 で保存された CSV は文字化けしやすくなります。反対に、Shift_JIS や GBK の CSV を UTF-8 として読むソフトでも文字化けが起きます。

このページではどうやって直すのですか？

ファイルのバイト列から Shift_JIS、GB18030/GBK、Windows-1252、UTF-8、UTF-8 BOM のどれかを推定し、プレビューを表示します。判定は推定なので、表示がおかしいときは文字コードを選び直せます。保存すると UTF-8 の CSV になり、初期設定では Windows の Excel 向けに BOM を付けます。複数ファイルは zip にまとめて保存でき、見出しが同じファイルは 1 つに結合することもできます。

ファイルはアップロードされますか？

いいえ。読み込みと変換はブラウザの JavaScript（TextDecoder）だけで行い、ファイルの中身をサーバーへ送る処理はありません。アカウント登録は不要で、アクセス解析や追跡用のスクリプトも入れていません。
